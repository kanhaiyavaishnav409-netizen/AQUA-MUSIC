# AQUA MUSIC

Android music player starter project. Build debug APK with GitHub Actions (`Build AQUA MUSIC APK`).

Features in this starter: local audio file selection, playback queue, shuffle/repeat, Media3 background playback service and lock-screen media session controls, aqua glass-style Compose UI.

Build: run the `Build AQUA MUSIC APK` workflow from the Actions tab. Download the `aqua-music-debug-apk` artifact and install `app-debug.apk` on Android. This is a debug APK, not a Play Store release.

Note: folder browsing, embedded album-photo artwork, and equalizer/bass boost are not implemented in this starter yet.
